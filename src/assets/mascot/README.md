# QuickDeck 마스코트 에셋

아직 에셋이 없습니다. 이 폴더는 자리만 잡아 둔 것입니다.

- 방향: 작고 둥근 흰색 AI 로봇. 둥근 머리·몸체, 검은색(또는 매우 짙은) face screen, 그 안에 단순한 cyan/mint 계열 눈과 표정. 친근하고 과한 SF/메카닉 느낌 없음.
- 형식: 투명 배경 PNG(1x·2x) 또는 정적 SVG(스크립트·외부 참조 없음). 표정 변형이 있으면 `mascot-<expression>.png`.
- 연결: `src/features/branding/Mascot.tsx` 의 `MASCOT_ASSET` 에 import 한 URL 을 넣으면 `<Mascot />` 이 그리기 시작합니다. 에셋이 없으면 아무것도 그리지 않습니다.
- 사용 원칙: 설정 정보·빈 덱 안내·첫 실행·업데이트 완료·친근한 안내에만. 메인 덱 버튼 영역을 침범하거나 항상 크게 보이지 않습니다.
- 임의로 생성하거나 인터넷에서 가져온 이미지를 넣지 않습니다.
